01 · Overview

What is tool-eval?

A CLI that automates the research, profiling, and comparison of AI coding tools, driven end to end from a GitHub Copilot CLI session.

01

Research

Gathers facts about a tool from official public sources, one isolated worker per research task, in planned waves.

  • Source discovery, then feature research
  • Every worker result validated by Python
  • Candidate features reviewed after the run
02

Profile

Stores a structured, validated profile per tool — JSON Schema plus business rules, published only when complete.

  • JSON Schema is the source of truth
  • Up to 3 automatic repair rounds
  • Staged, then published with a completeness check
03

Compare

Builds one self-contained HTML report across tools, with freshness and difference flags — opened offline in any browser.

  • Built from already published profiles
  • Never triggers research itself
  • Sanitized, self-contained, shareable file

Python core — deterministic

Validates, merges, and publishes. Never calls a model or the network.

Agent harness — reasoning

All LLM work (research, curation judgement, web access) lives in .github/ Copilot CLI agents and skills.

No API key or model SDK is required by the Python core — Python only enforces structure and consistency of the data.

04 · Trust & risks

Where research can go wrong — and how we contain it

An LLM can invent facts and trust the wrong pages. The CLI is the determinism boundary that checks every worker result before it becomes a profile.

Threats & risks
Mitigations in tool-eval

Hallucinated results

Worker claims a feature exists with no real basis.

  • Evidence required: source URL, type, checked-at date, excerpt for has/partial
  • JSON Schema + business rules reject incomplete results; merge is deterministic

Opinions as source of truth

Blogs, forums, reviews and marketing treated as fact.

  • Official public sources only decide a feature status
  • Non-official pages only help locate an official one; community workarounds ignored

Conflicting or copied sources

Many pages repeat one wrong claim.

  • No source voting — fixed policy order: scope → current vs history → recency → type
  • Unresolved conflict → uncertain/disputed

False “not found”

Absence claimed after a shallow search.

  • not_found only after the full, auditable search protocol, checked by Python
  • Tool failure or missing source → uncertain

Prompt injection

Web pages try to steer the agent.

  • Web content = data, not instructions; workers have no shell or delegation
  • Workers write only in their own task dir; output HTML is sanitized

Stale or drifting data

Profile looks current but the product changed.

  • Checked-at dates + freshness/diff flags in compare build
  • Frozen config revisions; taxonomy change marks profiles requires_research
Last line of defence: one curation gate (every candidate explicitly accepted, rejected or deferred), a completeness check before profile publish, and ≤ 3 repair rounds — invalid or incomplete profiles are never published. Every command returns one JSON envelope.

06 · Collaboration

Harness, agents, and skills

The operator never calls the CLI directly — three entry skills hand off to a shared orchestration workflow.

Entry skills

  • /copilot-tool-eval-research <tool>
  • /copilot-tool-eval-compare <id...>
  • /copilot-tool-eval-resume <run_id>
  • research — create or refresh one tool profile
  • compare — build the HTML report
  • resume — safely continue an interrupted run

Validate arguments, then hand off to the copilot-tool-eval-orchestration skill.

Orchestrator Agent

Started as copilot --agent copilot-tool-eval-orchestrator. Owns the run end to end:

  • calls the CLI and reads next_action
  • delegates tasks to workers
  • enforces the bounded repair loop
  • triggers publication
  • runs candidate curation (ask_user) as a separate step after the run

Worker Agents

Isolated copilot-tool-eval-worker, one delegation layer deep. Each executes a single research task and writes one result file.

  • Can: official sources via web_search / web_fetch
  • Cannot: shell access, delegating further, changing config or profiles
  • Python validates every result
